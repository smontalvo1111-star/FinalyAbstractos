# Final y Abstractos

Proyecto organizado a partir de los tres laboratorios de la guía **Final y abstractos en Java**.

## Estructura

- `Laboratorio 1`: uso de `final` en propiedades y `static final` en constantes.
- `Laboratorio 2`: clase abstracta, método abstracto, herencia y polimorfismo.
- `Laboratorio 3`: integración de `final`, clases abstractas, métodos abstractos y sobrecarga.

Cada laboratorio tiene su propia carpeta `src` y un paquete Java distinto (`laboratorio1`, `laboratorio2`, `laboratorio3`) para evitar conflictos entre los tres archivos `Main.java`.

## En IntelliJ IDEA

1. Descomprime y abre la carpeta `Final y Abstractos` como proyecto.
2. En cada laboratorio, haz clic derecho sobre su carpeta `src` y selecciona **Mark Directory as > Sources Root** si IntelliJ no la reconoce automáticamente.
3. Ejecuta:
   - `laboratorio1.Main` para el Laboratorio 1.
   - `laboratorio2.Main` para el Laboratorio 2.
   - `laboratorio3.Main` para el Laboratorio 3.

Los tres laboratorios pueden convivir dentro del mismo proyecto porque cada uno usa un paquete diferente.
